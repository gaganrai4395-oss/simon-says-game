
# 🎮 Simon Says Game

A fun memory-based game built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

[Play Simon Says Game](https://gaganrai4395-oss.github.io/simon-says-game/)

## 📌 About the Project

Simon Says Game is a memory game where players follow a sequence of colored buttons. The sequence becomes longer as the player progresses through each level.

## ✨ Features

- Interactive color button gameplay
- Increasing difficulty with each level
- Level tracking
- High score tracking
- Game-over functionality
- Keyboard-based game start

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners

## 🧠 What I Learned

- JavaScript DOM manipulation
- Event handling
- Arrays and sequences
- Functions and conditional logic
- Managing game state
- Using Git and GitHub

## 💻 How to Run

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

3. Open `index.html` using Live Server or your browser.
